# CHECKPOINT - Semaine 1

## Gate de validation

Pour considerer cette semaine comme VALIDEE, coche toutes les cases des
sections 1 et 2. Les questions de comprehension servent ensuite a identifier
ce qu'il faut relire.

### 1. Compilation (Obligatoire)

Utilise les [commandes MSVC, GCC ou Clang du README](README.md#compilation-rapide).

- [ ] `lessons/01-hello-world.c` compile sans erreur
- [ ] `lessons/02-variables.c` compile sans erreur
- [ ] `lessons/03-if-else.c` compile sans erreur
- [ ] `lessons/04-loops.c` compile sans erreur
- [ ] `lessons/05-functions.c` compile sans erreur

### 2. Exercices (Obligatoire)

- [ ] [`exercises/ex01-calculator.c`](exercises/ex01-calculator.c) compile et gere +, -, *, / et la division par zero
- [ ] [`exercises/ex02-fizzbuzz.c`](exercises/ex02-fizzbuzz.c) compile et affiche correctement 1-20 avec Fizz/Buzz/FizzBuzz
- [ ] [`exercises/ex03-string-reverse.c`](exercises/ex03-string-reverse.c) compile et inverse "HELLO" en "OLLEH"

### 3. Comprehension (Auto-evaluation)

- [ ] Je peux expliquer ce que fait `#include <stdio.h>`
- [ ] Je connais la difference entre `=` et `==`
- [ ] Je sais quand utiliser `for` vs `while`
- [ ] Je peux creer une fonction qui retourne une valeur

## Livrable

A la fin de cette semaine, tu dois avoir :

```
Un programme "calculatrice" qui fonctionne
= preuve que tu maitrises variables, conditions, et fonctions
```

## Verification

1. Compile les cinq lessons avec la boucle correspondant a ton compilateur dans
   le [README](README.md#compilation-rapide).
2. Compile chaque exercice apres l'avoir complete.
3. Execute les trois exercices et compare leur comportement aux criteres de la
   section 2.

Si les cinq compilations et les trois exercices sont valides, tu es pret pour
la Semaine 2.

## En cas de blocage

1. Relis la lesson concernee
2. Regarde les indices dans le fichier exercice
3. Compare avec la solution (en dernier recours)
4. Pose ta question avec le code exact et l'erreur

## Pret pour la suite ?

Si tu as coche toutes les cases obligatoires des sections 1 et 2, passe a la
[Semaine 2 : pointeurs et memoire](../02-memory-pointers/README.md) !
