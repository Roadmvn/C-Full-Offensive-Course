# Code de conduite · Code of Conduct

[Français](fr/README.md) · [English](en/README.md)

## Français

### Comportements accueillants

Nous nous engageons à maintenir un espace d'apprentissage ouvert, respectueux et accessible. Soyez patient avec les débutants, critiquez les idées plutôt que les personnes, acceptez les corrections de bonne foi et respectez les expériences, identités et niveaux de compétence différents.

### Comportements inacceptables

Le harcèlement, les menaces, les insultes, la discrimination, la divulgation d'informations privées, les avances importunes, le détournement de contenu vers une activité non autorisée et toute perturbation délibérée ne sont pas acceptés.

### Portée

Ce code s'applique dans le dépôt, les issues, les pull requests, les Discussions et tout espace public où une personne représente officiellement le projet.

### Signalement et application

Signalez les problèmes de conduite au mainteneur du dépôt [@Roadmvn](https://github.com/Roadmvn) par l'intermédiaire de GitHub. Ne publiez dans une issue ou une Discussion que des informations pouvant être rendues publiques. Pour un abus sensible, utilisez les outils intégrés de signalement et de blocage de GitHub sans exposer de données privées.

Le mainteneur peut retirer ou modifier un contenu, demander un changement de comportement, limiter une participation ou exclure une personne selon la gravité et la répétition des faits. Les signalements sont examinés de manière équitable, en limitant la diffusion des informations au nécessaire.

## English

### Welcoming behavior

We are committed to an open, respectful, and accessible learning space. Be patient with beginners, critique ideas rather than people, accept good-faith corrections, and respect different experiences, identities, and skill levels.

### Unacceptable behavior

Harassment, threats, insults, discrimination, disclosure of private information, unwelcome advances, redirecting course content toward unauthorized activity, and deliberate disruption are unacceptable.

### Scope

This code applies in the repository, issues, pull requests, Discussions, and any public space where someone officially represents the project.

### Reporting and enforcement

Route conduct concerns to repository maintainer [@Roadmvn](https://github.com/Roadmvn) through GitHub. Put only information that is safe to make public in an issue or Discussion. For sensitive abuse, use GitHub's built-in reporting and blocking tools without exposing private details.

The maintainer may remove or edit content, request a behavior change, restrict participation, or exclude someone according to the severity and repetition of the behavior. Reports will be reviewed fairly and shared only as needed for enforcement.
